> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `https://www.muhammedikbalbakirci.com/` adresini tek canonical origin olarak kullanan, ölçülebilir teknik SEO temeli güçlü bir Astro çıktısı üretmek.

**Architecture:** SEO bilgileri `src/lib/seo.ts` içinde merkezi tutulacak. `BaseLayout.astro` bu bilgiyi canonical, meta, JSON-LD ve breadcrumb çıktısına dönüştürecek. Astro endpoint'i collection verisinden sitemap üretecek; küçük bir Node test dosyası source/build guard'larını doğrulayacak.

**Tech Stack:** Astro 5 static output, Astro content collections, TypeScript endpoint, Node built-in test runner, PowerShell verification.

**Spec:** `docs/superpowers/specs/2026-09-12-seo-100-goal.md`

## Global Constraints

- Canonical origin: `https://www.muhammedikbalbakirci.com`
- Site language: Turkish (`tr`)
- No fabricated address, reviews, ratings, credentials, social profiles, citations, or medical claims.
- No HowTo schema; no new FAQ schema for Google SERP benefit.
- Preserve unrelated existing user changes and do not reset/delete the dirty worktree.
- Build validation must use the real `npm run build` command.
